Node Practice

A collection of small backend projects built with Node.js to practice building REST APIs, data validation, and server-side concepts.

Projects
1. Movies REST API

A REST API for managing a movie catalog (GET, POST, PATCH, DELETE), with schema validation using Zod and CORS configured for specific origins. Includes a simple HTML client to test it in the browser.

Tech stack overview

Node.js · Express · Zod · CORS
